# موقع شركة الخيال

موقع ثابت بالعربية، مستضاف على GitHub Pages.

## مصدر المحتوى والنشر

ملفات HTML في جذر المستودع هي **المصدر المعتمد للمحتوى**. `build_site.py` لا يعيد توليد الصفحات؛ بل ينسخ قائمة صفحات الإنتاج المعتمدة وملفات الأصول إلى `dist/`. لا تشغّل مولدًا قديمًا فوق الصفحات يدويًا.

```bash
python3 scripts/validate_site.py
python3 build_site.py
python3 scripts/validate_site.py --root dist
```

يُنفّذ سير عمل GitHub Actions هذه الفحوصات ثم ينشر `dist/` إلى GitHub Pages. صفحات التصميم التجريبية ليست ضمن قائمة النشر. سكربتات التعديلات القديمة معطّلة عمدًا لأنها كانت تعيد كتابة الصفحات بقوالب قديمة.

## قواعد صيانة مهمة

- عند إضافة صفحة إنتاج، حدّث قائمة الصفحات في `build_site.py` و`scripts/validate_site.py` و`manus-routes.json` و`sitemap.xml` معًا.
- حافظ على أن يكون لكل صفحة عنوان ووصف ووسم canonical وبيانات مشاركة اجتماعية صحيحة، وأن تشير الروابط والروابط ذات المراسي إلى أهداف موجودة.
- لا تضف مدن التغطية أو ساعات العمل أو الأسعار أو التقييمات إلا بعد تزويدنا بمعلومات مؤكدة من مالك النشاط.
- أزرار الهاتف وواتساب تتيح التواصل مباشرة. لم يُضف تتبعًا تحليليًا خارجيًا لأن المستودع لا يحتوي على مزود تحليلات أو معرّف قياس أو إعداد موافقة خصوصية؛ يلزم تحديد هذه الخيارات قبل إرسال بيانات إلى خدمة خارجية.
